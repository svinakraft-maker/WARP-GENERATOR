# WARP Config Generator for AmneziaWG 2.0

Генератор конфигов WARP для AmneziaWG с автоматическим получением свежих ключей и эндпоинтов.

## Требования

- Python 3.6+
- Никаких внешних зависимостей (работает из коробки)

## Установка

Просто скачайте файл `warp_generator.py` и запустите:

```bash
python3 warp_generator.py
```

## Возможности

✅ **Генерация приватных ключей** - криптографически стойкие ключи WireGuard  
✅ **Свежие эндпоинты** - автоматический выбор рабочих серверов Cloudflare  
✅ **Поддержка IPv4/IPv6** - двойной стек или только IPv4  
✅ **AmneziaWG 2.0 формат** - все необходимые параметры обфускации  
✅ **Настройка DNS** - возможность указать свои DNS серверы  
✅ **Сохранение конфигов** - удобная выгрузка в файлы .conf  

## Использование

### Интерактивный режим

```bash
python3 warp_generator.py
```

Программа предложит меню:
1. Сгенерировать новый конфиг
2. Выбрать тип подключения (IPv4+IPv6 или только IPv4)
3. Настроить DNS серверы
4. Сохранить конфиг в файл
5. Выход

### Пример конфига

```ini
[Interface]
PrivateKey = <ваш_приватный_ключ>
Address = 172.16.0.2/32
Address = 2606:4700:110::/128
DNS = 1.1.1.1,1.0.0.1
MTU = 1280

# AmneziaWG specific settings
Jc = 3
Jmin = 500
Jmax = 1500
S1 = 0
S2 = 0
H1 = 0
H2 = 0
H3 = 0
H4 = 0

[Peer]
PublicKey = bmXOC+F1FxEMF9dyiK2H5/1SUtzH0JuVo51h2wPfgyo=
AllowedIPs = 0.0.0.0/0,::/0
Endpoint = engage.cloudflareclient.com:2408
PersistentKeepalive = 25
```


## Примечания

- Приватные ключи генерируются локально и никуда не отправляются
- Публичный ключ WARP фиксированный: `bmXOC+F1FxEMF9dyiK2H5/1SUtzH0JuVo51h2wPfgyo=`
- Эндпоинты выбираются случайно из списка рабочих серверов Cloudflare
- Для полной интеграции с API WARP рекомендуется установить `pynacl`: `pip install pynacl`
